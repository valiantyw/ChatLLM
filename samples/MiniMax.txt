MiniMax-M2.7 兼容 OpenAI 和 Anthropic 接口协议，适用于代码助手、Agent 工具、AI IDE 等多种场景。


接口概览
MiniMax 开放平台 API 接口能力概览，包括文本、语音、视频、图像、音乐和文件管理等多模态能力。

获取 API Key
按量付费：通过 接口密钥 > 创建新的 API Key，获取 API Key
Token Plan：通过 订阅管理 > Token Plan，查看 Token Plan Key

文本生成
文本生成接口使用 MiniMax M2.7 根据输入的上下文，让模型生成对话内容、工具调用。
可通过 HTTP 请求、Anthropic SDK（推荐） 或 OpenAI SDK 接入。

模型名称            输入输出总 token    模型介绍
MiniMax-M2.7       204800	          开启模型的自我迭代 (输出速度约60tps)



API 快速接入  - python
---------------------
    import requests

    url = "https://api.minimaxi.com/v1/text/chatcompletion_v2"

    payload = {
        "model": "MiniMax-M2.7",
        "messages": [
            {"role": "user", "content": "你好"}
        ]
    }
    headers = {"Authorization": "Bearer <token>"}

    response = requests.post(url, json=payload, headers=headers)
    print(response.text)


Anthropic API 兼容  - python
----------------------------
    import requests

    url = "https://api.minimaxi.com/anthropic/v1/messages"

    payload = {
        "model": "MiniMax-M2.7",
        "messages": [
            {
                "role": "user",
                "content": "你好"
            }
        ]
    }
    headers = {
        "Content-Type": "application/json",
        "X-Api-Key": "<api-key>"
    }

    response = requests.post(url, json=payload, headers=headers)

    print(response.text)


OpenAI API 兼容
---------------
import requests

url = "https://api.minimaxi.com/v1/chat/completions"

payload = {
    "model": "MiniMax-M2.7",
    "messages": [
        {
            "role": "system",
            "name": "MiniMax AI"
        },
        {
            "role": "user",
            "content": "你好",
            "name": "用户"
        }
    ]
}
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer <token>"
}

response = requests.post(url, json=payload, headers=headers)

print(response.text)
